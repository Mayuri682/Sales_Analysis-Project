
# Sales Analysis & Exploratory Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a sales dataset to understand customer demographics, purchasing behavior, order distribution, and sales performance across different regions, states, sectors, and product categories.

The analysis uses **Python, Pandas, NumPy, Matplotlib, and Seaborn** to clean, transform, analyze, and visualize the data.

## 🎯 Objectives

* Analyze the overall structure and characteristics of the sales dataset.
* Clean and prepare the data for analysis.
* Understand customer distribution across different zones and states.
* Analyze customers based on age group, gender, and marital status.
* Identify sectors generating the highest sales amounts.
* Analyze order volume by state, zone, and age group.
* Identify the most popular product categories.
* Visualize important business insights using charts and graphs.

## 🛠️ Technologies And Library Used

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Development and analysis environment
* **Excel** – Input and cleaned dataset format

## 🔄 Data Preparation and Cleaning

The notebook performs several preprocessing steps before visualization:

* Inspects the dataset using functions such as `head()`, `tail()`, and `info()`.
* Identifies unique zones, states, and product categories.
* Removes unnecessary columns such as `Status` and `unnamed1`.
* Converts the `Marital_Status` values into meaningful labels:

  * `0` → Single
  * `1` → Married
* Renames the `Occupation` column to `Sector`.
* Exports the cleaned dataset as **`Cleaned Project Data.xlsx`**.
* Exports lists of states and product categories as CSV files.

## 🔍 Key Findings

Some of the major observations from the analysis include:

* The **Central zone** has the highest user and order volume, while the **Eastern zone** has the lowest.
* The **26–35 age group** represents the largest customer segment and has the highest order activity.
* The **IT sector** generates the highest total amount among the analyzed sectors.
* **Uttar Pradesh** has the highest total order volume and the highest number of users among the states analyzed.
* **Food, Clothing, and Electronics** are the three leading product categories by order volume.
* Single customers are more numerous than married customers across the analyzed age groups.
* Female users outnumber male users in most age groups according to the analysis.
